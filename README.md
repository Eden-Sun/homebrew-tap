# Eden-Sun Homebrew tap

```bash
brew install eden-sun/tap/agents-manager
agents-managerd serve   # then open http://127.0.0.1:7788
```

Formulae:

- [`agents-manager`](https://github.com/Eden-Sun/agents-manager): web UI for Claude Code, Codex, Grok and Antigravity CLI agents running in herdr. Prebuilt for macOS arm64 and Linux x86_64 / arm64.
